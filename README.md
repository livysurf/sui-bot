# sui 🟢

A Discord bot for community servers: levels, games, giveaways, reminders, birthdays, moderation tools, and a live activity dashboard.

🌐 **Website:** [suidiscordbot.netlify.app](https://suidiscordbot.netlify.app)
➕ **Add to Discord:** [Invite sui](https://discord.com/oauth2/authorize?client_id=1565315112686977156&permissions=8&scope=bot+applications.commands)

---

## Features

- **Levels and XP:** members earn XP by chatting, with level-up messages and role rewards.
- **Games:** trivia, flag guessing, word unscramble, tic tac toe, rock paper scissors duels, and Mafia with buttons.
- **Community tools:** giveaways, reminders, birthdays, reaction roles, starboard, and daily challenges.
- **Moderation:** slowmode, lock and unlock, role tools, and a clean-up command.
- **AI helper:** answers members in ticket channels, with a personality you can set per server.
- **Activity dashboard:** server owners sign in with Discord to see messages, commands, active members, and an XP leaderboard.

## Commands

Type `/help` in any server to see every command, grouped by category.

## Privacy

sui stores counts, IDs, and settings. It never stores message text. Server owners can only see their own servers' stats. Read the full policy at [suidiscordbot.netlify.app/privacy.html](https://suidiscordbot.netlify.app/privacy.html).
